# Day 0 — Project Introduction & Preparation

## 1. Introduction

This project is part of the **TotalThreat 7-Day Portfolio Challenge**, a hands-on training experience designed to develop practical IT support, identity management, and cybersecurity skills.

The challenge simulates working as a **Junior IT & Identity Support Specialist** for Northstar Medical Group (NMG), a fictional healthcare company based in Seattle, Washington.

The objective is to address a realistic business problem by building an Active Directory environment and developing a basic employee identity lifecycle management process.

## 2. Business Background

Northstar Medical Group is experiencing rapid organizational growth, but its identity management procedures have not kept pace.

The company has an HR system; however, the process of creating employee accounts and assigning permissions remains slow, repetitive, and inconsistent.

These weaknesses create administrative inefficiencies and increase potential security risks.

## 3. Problem Statement

The organization faces several identity management challenges:

| Business Problem | Potential Impact |
|---|---|
| Manual employee onboarding | Delays and account creation errors |
| Unorganized departments | Difficulties managing employee identities |
| Inconsistent access assignments | Incorrect or unnecessary permissions |
| Overprivileged accounts | Increased risk of unauthorized access |
| Weak identity governance | Potential HIPAA and PHI security concerns |

The central business problem is the lack of a structured employee identity lifecycle process.

## 4. Assigned Role

**Position:** Junior IT & Identity Support Specialist

**Organization:** Northstar Medical Group (Simulated)

My assignment is to help rebuild the organization's identity management environment and establish a more consistent process for managing employee accounts and access.

The project will involve:

- Creating the NMG.com Active Directory domain.
- Organizing departments.
- Provisioning employee accounts.
- Assigning permissions using RBAC and ABAC principles.
- Applying Group Policy.
- Troubleshooting an IT support issue.
- Documenting implementation and results.

## 5. Proposed Solution

The proposed solution is to establish a centralized identity management environment using Microsoft Active Directory.

Active Directory will provide the foundation for:

**Centralized Account Management**

Managing employee identities from a common administrative environment.

**Organizational Structure**

Organizing user accounts by department using Organizational Units.

**Standardized Access Management**

Assigning permissions according to employee responsibilities and relevant attributes.

**Security Policy Management**

Using Group Policy to apply consistent Windows configuration and security settings.

**Employee Lifecycle Support**

Developing more consistent procedures for employee onboarding and access management.

## 6. Project Objectives

The main objectives of the challenge are to:

1. Establish a functional Windows Server environment.
2. Deploy Active Directory Domain Services.
3. Create the NMG.com domain.
4. Build a structured organizational hierarchy.
5. Manage employee accounts and access permissions.
6. Apply appropriate security controls.
7. Investigate and resolve an IT support issue.
8. Produce a documented GitHub portfolio project.
